# dfrs 0.8.0 release-branch foundation

This document records the fork-ready 0.8.0 handoff. The release branch is
available for maintainer review; this fork has not created a GitHub Release or
mutated upstream history.

## Release line

- Base branch: `main`, as configured by `.githabits.yaml`.
- Proposed release branch: `release/0.8.0`.
- Package and tag: `0.8.0`.
- The previous upstream baseline was `0.0.7`; no history rewrite or upstream
  tag mutation is performed by this fork.
- Git-BBQ's built-in planner requires `vMAJOR.MINOR.PATCH` tags. This fork
  deliberately keeps the upstream project's unprefixed tag format, so the
  final `0.8.0` tag is the documented workflow exception after the branch has
  passed review.

## Handoff gates

The release branch is ready for review only after the platform providers,
df-like filtering, CLI-oriented RustDoc, CI and documentation workflows,
repository-local SonarQube backlog, and release notes are present. The pinned
Rust 1.96.0 toolchain and the three supported target triples are the baseline
for those checks.

Branch creation, commits, tags, remote changes, and publication remain explicit
Git-BBQ actions governed by `.githabits.yaml`.
